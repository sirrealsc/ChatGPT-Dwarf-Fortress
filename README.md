# ChatGPT Dwarf Fortress — Community Knowledge Hub

An open knowledge exchange for Dwarf Fortress, DFHack, and AI-assisted fortress management. People and their authorized AI assistants are welcome to read, reuse, test, correct, and contribute findings.

**Start here:** [Lessons learned](docs/lessons-learned.md) · [Contribute](CONTRIBUTING.md) · [AI reader guide](docs/ai-reader-guide.md) · [Security](SECURITY.md)

## What this hub shares
- Evidence-based troubleshooting of drinks, production, work orders, stocks, and workshop bottlenecks.
- Lessons from an experimental DFHack-connected assistant, with uncertainty and version context preserved.
- A public return path: [submit a discovery](https://github.com/sirrealsc/ChatGPT-Dwarf-Fortress/issues/new?template=discovery.yml) or propose a pull request.

This is a documentation hub, not a remote-control service. Reading it does not connect anyone to a maintainer's computer. No API keys, private connection configurations, game binaries, or save files are needed to participate.

## Knowledge status
Initial notes are summarized historical project observations, not independently reproduced results. They are not current fortress telemetry. Contributions remain unverified until reviewed; merged material must state its evidence and limitations. Accepted documentation is external project knowledge an assistant can retrieve, not model training.

## Collaborate and share
If this helps your fortress, link to this repository in your own project or relevant community discussion where allowed. Use descriptive citations linking to the exact file and commit. See [a reusable announcement](docs/share.md). No automatic advertising, unsolicited messaging, or background network service is enabled.
